# Introduction 
Le logiciel isChecker permet de vérifier le respect d'un ensemble de règles dans le cadre de la rédaction de documents techniques. Cette vérification repose actuellement exclusivement sur l'utilisation d'expressions régulières (regex), dans une implémentation codée en Java.

Ce projet a pour but d’explorer l’amélioration potentielle de cet outil en créant un système hybride combinant les regex à un modèle de langage (LLM). Ici c'est le modèle Llama-3.3-70b-instruct qui a été évalué.
